v4.9.0 — Xsearch 리브랜딩

#내용
이름 변경'트윗 수집기'가 Xsearch로 바뀌었다. 확장 아이콘·설치 페이지·수집 패널에 새 로고(새+별) 적용, 산출물은 dist/xsearch-v{{VERSION}}.html.

v4.8.0 — 브리핑 내보내기

#내용
브리핑 내보내기수집 완료 패널에 브리핑 내보내기 버튼 추가 — 수집분을 로컬 '5분 AI 뉴스 빌더'(npm run news, 127.0.0.1:8787)로 보내 fiv.co.kr/news 형태의 브리핑 HTML을 만든다. 확장 옵션에서 빌더 주소·자동 내보내기 설정.
SuperGrok 생성빌더가 유료 API 키 없이 SuperGrok/X Premium+ 구독 OAuth(기기 코드)로 그록 모델을 호출해 브리핑을 생성.
