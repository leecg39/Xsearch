v5.1.0 — 관심사 카테고리 필터

#내용
관심사 칩수집 패널에서 전체 / AI / 개발 / 금융 / 비즈를 바로 고르면 해당 프리셋으로 필터링. 선택은 localStorage·확장 설정에 저장.
옵션 UI설정 페이지도 같은 관심사 카테고리 카드로 선택. 카테고리 고르면 필터 기본값이 관심사만으로 맞춰짐.

v5.0.1 — Threads.com 도메인

#내용
ThreadsMeta가 threads.net → threads.com으로 옮긴 뒤에도 수집기가 동작하도록 호스트 매칭·확장 권한을 갱신.

v5.0.0 — 토픽 카테고리 · 멀티 소스

#내용
토픽 프리셋필터를 AI 하드코딩에서 AI / 개발·테크 / 경제·금융 / 스타트업·비즈 / 자유 입력으로 선택. 브리핑도 같은 토픽으로 생성.
멀티 소스X 외에 Reddit(공개 JSON API), Threads(DOM), LinkedIn(DOM, 옵션 기본 OFF)에서 수집. CSV 끝에 source 컬럼.
LinkedIn봇 탐지·계정 제한 위험이 커서 확장 옵션에서 직접 켜야 동작합니다. 느린 딜레이·소량만 권장.

v4.9.0 — Xsearch 리브랜딩

#내용
이름 변경'트윗 수집기'가 Xsearch로 바뀌었다. 확장 아이콘·설치 페이지·수집 패널에 새 로고(새+별) 적용, 산출물은 dist/xsearch-v{{VERSION}}.html.
발행 브랜드뉴스 빌더가 만드는 브리핑 페이지·아카이브의 발행명은 '오늘의 AI 브리핑'으로 변경 (기존 '5분 AI 뉴스').

v4.8.0 — 브리핑 내보내기

#내용
브리핑 내보내기수집 완료 패널에 브리핑 내보내기 버튼 추가 — 수집분을 로컬 '5분 AI 뉴스 빌더'(npm run news, 127.0.0.1:8787)로 보내 fiv.co.kr/news 형태의 브리핑 HTML을 만든다. 확장 옵션에서 빌더 주소·자동 내보내기 설정.
SuperGrok 생성빌더가 유료 API 키 없이 SuperGrok/X Premium+ 구독 OAuth(기기 코드)로 그록 모델을 호출해 브리핑을 생성.

v4.6.3 — 날짜 수정

#내용
파일명 날짜UTC 기준이라 한국시간 자정~오전 9시에 저장하면 전날 날짜(tw_2026-03-21.csv)로 나오던 버그 수정 — 기기 로컬 날짜 사용. 트윗 자체의 시간 컬럼은 UTC ISO 유지(DuckDB가 타임존 처리).
