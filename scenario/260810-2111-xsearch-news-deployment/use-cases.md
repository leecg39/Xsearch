# 핵심 유스케이스

## UC01 공개 독자

독자는 인증 없이 아카이브와 날짜별 브리핑을 읽고, 공유 시 1200×630 OG 카드가 표시되어야 한다. 관련 시나리오: S001, S013, S014, S025.

## UC02 인증 편집자

편집자는 Basic 인증 후 빌더를 열고 수집 JSON을 검증해 다이제스트 또는 AI 브리핑을 생성한다. 잘못된 입력은 파일을 만들기 전에 4xx로 거절되어야 한다. 관련 시나리오: S002, S006–S010, S015.

## UC03 Chrome 확장 사용자

사용자는 확장에서 원격 빌더로 수집 결과를 전송하고 자동으로 열린 빌더에서 데이터를 확인한다. 가져온 문자열은 실행 가능한 HTML이 되어서는 안 된다. 관련 시나리오: S003, S011, S016, S021.

## UC04 SuperGrok 사용자

사용자는 현재 브라우저에서 xAI 승인을 완료하고 토큰 만료 후에도 자동 갱신된 계정으로 모델을 조회·생성한다. 관련 시나리오: S004, S023, S024.

## UC05 운영자

운영자는 동시 작업·재시작·재배포 상황에서도 비용과 데이터 무결성을 통제하고, 운영 이미지와 저장소가 같은 상태임을 보장한다. 관련 시나리오: S005, S017–S020, S022, S025.
